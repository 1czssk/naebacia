# НАЕБАЦИЯ v1.59 🎃 — PWA + профиль Красного Кута

## Загрузка на GitHub Pages
1. Распакуйте ZIP. Загрузите файлы и папки в **ту папку репозитория**, из которой GitHub Pages публикует сайт (часто корень репозитория, иногда `/docs`). Не загружайте одну внешнюю папку целиком, иначе `index.html` окажется не там.
2. Должны быть доступны: `index.html`, `app.js`, `manifest.json`, `sw.js`, `regions/krasny-kut.json`, две PNG-иконки.
3. Перейдите на HTTPS-адрес своего GitHub Pages; обычная веб-версия работает по ссылке. В Chrome на Android через меню можно установить приложение; на iOS — «Поделиться → На экран Домой».
4. При замене старого файла `index.html` убедитесь, что ваша существующая ссылка ведёт именно на этот файл. Ранее сохранённые данные `localStorage` обычно сохраняются на **том же origin**, но для изменения пути/домена это не гарантируется. Перед обновлением экспортируйте важный журнал РВ.

## Данные
- В `regions/krasny-kut.json` находятся опорные точки, радиостанции, маршруты, зоны, сектора и численное значение магнитного склонения 11° **как в v1.58**. Эти данные не были перепроверены и могут быть устаревшими.
- Активен **только** Красный Кут. Переключателя районов и пустых фиктивных профилей нет.
- Схемы малого/большого круга пока рассчитываются существующим кодом v1.58, специфичным для Красного Кута; для второго аэродрома их нужно отдельно вынести в профиль после проверки исходных данных.
- `app.js` — исходная логика всех вкладок и HSI; при извлечении данных алгоритм не заменяли.

## Офлайн
- PWA кэширует программную оболочку и профиль, старается кэшировать библиотеки Leaflet с CDN.
- **Фоновые карты/тайлы не сохраняются заранее**, поэтому карта без интернета может быть пустой. Для полётов необходимы независимые проверенные источники навигации.
- GPS в фоне при блокировке телефона может останавливаться; PWA это не исправляет.

## Для разработчика
- Настройки HSI, журнал РВ и остальные старые ключи `localStorage` оставлены прежними.
- `sw.js` использует `network-first` для файлов приложения и `cache-first` для CDN-библиотек. При следующем релизе обновите `CACHE`, чтобы корректно удалялся старый кэш.
- Этот комплект предназначен для сервера/HTTPS. Если открыть `index.html` через `file://`, загрузка JSON через `fetch` может быть заблокирована — используйте GitHub Pages или локальный `python -m http.server`.
