# НАЕБАЦИЯ v1.65 — исправление регионов и первый набор Сасово

Номер приложения остаётся **v1.65**. PWA-кэш обновлён до `naebacia-v1-65-r2-sasovo-regions`.

## Регионы
- **Глобальный:** никакие местные штатные маршруты, зоны, секторы или круг не отображаются. Общие НРТС и пользовательские маршруты остаются доступны.
- **Красный Кут:** только штатные маршруты А4, А5, Местный, Гагарин туда/обратно; местные зоны, секторы и круг Красного Кута.
- **Сасово:** только маршруты №453–462, два отдельных маршрута перелёта на Пителино и обратно, четырнадцать зон (№1–8 пилотажные, №9–14 полётов по приборам). **Круга и секторов Сасово нет**, их переключатели скрыты. Зоны и маршруты Красного Кута не рисуются.
- Рабочая навигация, HSI, маршрут, GPS, SIM и вручную заданное магнитное склонение не сбрасываются при переключении региона.
- Переключение региона сохраняется между перезапусками. При выборе Красного Кута или Сасово карта центрируется на местном исходном пункте, **если нет действующего GPS/SIM-полёта**.
- При старте SIM с выбранным регионом **Сасово** исходная точка — **п/п Сасово 2 (54°21′24″ N, 41°58′42″ E)**. Активный SIM не телепортируется при смене региона. Действительный GPS-полёт также не телепортируется.
- Координата **Сасово 2** из схемы маршрутов не идентична координате КТА аэродрома **UUBG** из отдельной справки. Для старта учебных маршрутов и SIM используется именно Сасово 2.

## Источники / оговорки
Данные перенесены с предоставленных пользователем изображений: учебные маршруты 2.2.8.1, зоны 2.2.8.2 и схема пилотажных зон аэродрома Сасово. Координаты перенесены из таблиц, радиусы зон — из подписей на схеме. В опубликованном тексте маршрута №461 встречается запись «54°23′60″» для Котелино — при переносе нормализована до 54°24′00″. Не применять без проверки актуального АИП и NOTAM; это учебное приложение, не сертифицированная навигация.
