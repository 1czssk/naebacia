# НАЕБАЦИЯ v1.65 — перемещение окошка линейки

- За пунктирный заголовок «⠿ 📐 А → Б» можно перетаскивать всю плашку.
- Кнопки расстояния, МПУ/ИПУ, направления и закрытия работают по отдельному тапу без перетаскивания.
- На телефоне используется Pointer Events и захват одного указателя; перемещение двух маркеров линейки на карте не изменяется.
- Плашка ограничена границами экрана и корректируется при изменении размера окна.
- Сохранены отдельные пилотажные зоны №1–8 и зоны полётов по приборам №9–14 в Сасово, без переключателя секторов.
- Номер версии остался 1.65, PWA-кэш обновлён.
