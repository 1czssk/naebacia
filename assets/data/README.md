# НАЕБАЦИЯ — маршрутные НРТС России из АИП ENR 4.1

Источником `navaids-russia.json` служит предоставленный пользователем файл `enr4.1.pdf`, 13 страниц. Извлечены 342 записи: 129 NDB, 94 VOR/DVOR (включая VOR/DME), 119 отдельных DME.

- Сохраняются исходные позывные, частоты, каналы (где есть), координаты антенн, обозначение системы координат и режим работы.
- У каждого элемента `sourcePage` и `sourceDate` — страница и дата листа исходного PDF.
- Старые аэродромные приводы по AD 2.19 остаются в `regions/` и не заменяются маршрутным каталогом.
- DME-only не являются VOR и не дают радиала. Для них можно видеть только справочное расстояние по карте (не реальное измерение наклонной дальности DME).
- Данные в системах ПЗ-90.02, ПЗ-90.11 и WGS-84 хранятся с обозначением системы. Преобразование между геодезическими датумами не производится.
- H24 на листе не гарантирует фактическую работу сегодня; ограниченные часы и метки HS/HO сохраняются.
- Перед использованием в полёте сверять действующие AIRAC и NOTAM. Приложение не сертифицировано как основное навигационное средство.
